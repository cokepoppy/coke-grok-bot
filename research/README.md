## 逐帧工具

工具仅依赖 Node.js、FFmpeg 和 FFprobe。完整本地视频可用：

```sh
node scripts/extract-reference-frames.mjs \
  --input research/videos/complete-video.mkv \
  --start 1328 --duration 5 \
  --out research/frames/example-1328
```

已安装可用 `yt-dlp` 时，可直接对公开 YouTube 源按时间截取，避免等待整个长视频下载：

```sh
HTTP_PROXY=http://127.0.0.1:7890 HTTPS_PROXY=http://127.0.0.1:7890 NO_PROXY=127.0.0.1 \
  node --use-env-proxy scripts/stream-reference-frames.mjs \
  --yt-dlp /path/to/yt-dlp --video 8xXhE25vJZY --format 248 \
  --start 1328 --duration 5 --out research/frames/example-1328
```

- 每次最多提取连续 5 秒的**全部源帧**，不做抽帧。每帧是原视频分辨率的 PNG，并记录源 PTS、时间、顺序和校验值；每 25 帧生成一张索引用缩略联系图。
- 缩略联系图用于找状态变化；布局和文字以原尺寸 PNG 核对。完整文件模式记录源文件 SHA-256；流式模式只能记录每帧 SHA-256，不能声称已校验完整视频。
- 工具仅创建新的输出目录，拒绝覆盖旧结果；拒绝读取未完成的 `.part` 文件。流式工具只在进程内使用临时签名 URL，通过本机 loopback 传给 FFmpeg，不输出或保存上游签名 URL。
- `node --test tests/reference-frames.test.mjs` 使用已知帧率的合成视频验证完整提帧、源时间戳和拒绝覆盖；这只验证工具，不证明已看完官方视频。
